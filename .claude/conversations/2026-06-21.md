# 2026-06-21 對話記錄

## 主題
新增 GitHub Actions CI/CD 工作流程

## 完成事項

### 建立 `.github/workflows/ci.yml`
- 基於 `.forgejo/workflows/ci.yml` 調整
- Runner 改用 `ubuntu-latest`
- 新增 `dtolnay/rust-toolchain@stable`（安裝 rustfmt + clippy）
- 新增 `actions/cache@v4` 加速 cargo 相依套件
- checkout 升至 `actions/checkout@v4`

### 建立 `.github/workflows/release.yml`
- 基於 `.forgejo/workflows/release.yml` 調整
- 新增 **macOS 平台** build job（Forgejo 版本沒有）
- 以標準 `actions/upload-artifact@v4` / `download-artifact@v4` 取代 Forgejo 專用 artifact action
- 發布使用 `softprops/action-gh-release@v2`
- Windows cleanup 改用 PowerShell（Forgejo 版用 Nushell）
- `manual_tag` 輸入改以 `env:` 傳入 shell，避免 injection 安全風險

## 對比 Forgejo vs GitHub 主要差異

| 項目 | Forgejo | GitHub Actions |
|------|---------|----------------|
| Runner | ubuntu-rust / ubuntu-runner | ubuntu-latest / windows-latest / macos-latest |
| Checkout | actions/checkout@v6 | actions/checkout@v4 |
| Artifact upload | forgejo/upload-artifact@v4 | actions/upload-artifact@v4 |
| Release | actions/forgejo-release@v2 | softprops/action-gh-release@v2 |
| macOS build | ❌ | ✅ 新增 |
| Cargo cache | ❌ | ✅ 新增 |
| Rust toolchain | rustup show | dtolnay/rust-toolchain@stable |
