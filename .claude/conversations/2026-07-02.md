# 2026-07-02 對話記錄

## 主題
- 使用者提出 Minecraft Java 版渲染堆疊演進矩陣（LWJGL 2 → LWJGL 3/Blaze3D → GL 3.2 Core → 宣稱 2026+ 轉 Vulkan），希望據此除錯跨平台圖形／函式庫問題。
- Claude 事實查核（web search）：Java Edition 26.2「Chaos Cubed」（2026-06-16）確實推出**實驗性、可選**的 Vulkan 渲染後端（需 Vulkan 1.2 + dynamic rendering + push descriptors；macOS 走 MoltenVK）。注意：是雙後端並行，OpenGL 仍在，並非完全轉換。
- 使用者選定方向：Launcher 端相容矩陣。盤點後發現預防端（JSON JVM 規則、arm64 LWJGL 替換、Rosetta x64 Java）已齊備，缺口在「崩潰後診斷」。
- 實作內容：
  - `mc_compat.rs`：新增 `diagnose_graphics_crash()` 特徵表（14 條特徵、7 類建議），涵蓋四個渲染世代的已知錯誤；模組頂部補上世代對照表文件。
  - `view/launch.rs`：行程監看改為捕捉 exit status，異常退出時掃描實例 log 比對特徵並經 `set_install_state` 顯示建議；無命中則顯示 exit code 提示。使用者主動停止不會誤報。
  - `mc_parser.rs`：Linux 啟動加 `_JAVA_AWT_WM_NONREPARENTING=1`（LWJGL2 世代 tiling WM/XWayland 灰屏緩解）。
  - 測試：`mc_compat` 4 tests 全過；clippy 無新警告。
- 環境備註：cargo 不在 PATH，需用 `~/.rustup/toolchains/1.94.0-aarch64-apple-darwin/bin`。
- **自動替換**：使用者問「可以自動替換嗎」→ 實作。根因：1.13–1.16.5 在 Apple Silicon 預設走 Rosetta x64 Java 時 `compat = None`，保留舊 GLFW 3.2.x → service port 崩潰；Intel Mac 同樣會中。
  - `mc_compat.rs`：新增 `LWJGL3_X64_OVERRIDE`（LWJGL 3.3.1 base + natives-macos x64，全 Mojang CDN，資料由 `data/1.19.2.json` 產生）與 `macos_override_for(version, arm64_java)`；x64 表只排除 `org.lwjgl:`，java-objc-bridge 保留原版。≤1.12 x64 維持原版不替換。
  - `launch.rs`：CustomPath 分支改為 macOS 全架構偵測（Intel 也套用）；VersionDefault 的 Rosetta 路徑與 arm64 gamma 缺貨 fallback 改用 x64 替換表。
  - CDN URL 已驗證（HEAD 200、size 相符）；mc_compat 6 tests 全過。
- **x64 替換表降版 3.3.1 → 3.2.3**：使用者實測 1.13.2 Forge 出現 exit 255。crash reports 顯示完整因果：22:44/22:54 是原始 `GLFW error 65544: service port for display`（舊 GLFW）；23:02 替換生效後變成 `GLFW error 65548: Regular windows do not have icons on macOS`——LWJGL 3.3.1 內建 GLFW 3.4 dev 對 `glfwSetWindowIcon` 報 FEATURE_UNAVAILABLE，而 1.13.x 啟動期 error callback 任何錯誤都拋例外。LWJGL 3.2.3（內建 GLFW 3.3.1）同時避開兩個 bug（MultiMC 標準解法）；Mojang CDN 無 3.2.3，artifact 改用 Maven Central（sha1/size 由 repo1 抓取驗證）。並新增 65548 診斷特徵（macOS 限定）。
- **誤判修正**：使用者在 macOS 實測跳出 Linux/Wayland 診斷——`GLFW error 65544` 是泛用 `GLFW_PLATFORM_ERROR`，在 macOS 上其實是 1.13–1.16 舊 GLFW 的「Failed to find service port for display」。修法：`CrashSignature` 加 `os` 欄位限定平台；macOS 的 service port 錯誤獨立成新建議（改選 arm64 Java 讓 launcher 換 LWJGL 3.3.1）；Linux 才把 65544 解讀為顯示連線問題。新增 `test_diagnose_os_gating` 回歸測試。
