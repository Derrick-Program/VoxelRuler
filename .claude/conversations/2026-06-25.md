# 2026-06-25 對話記錄

## 主題
修復 CreateInstanceDialog 的 accesskit crash

## 問題
點擊新增實例對話框中的 ComboBox（版本選擇 / Mod Loader 版本）時，app 在 macOS 上崩潰：

```
accesskit_consumer::tree::State::validate_global — Focused ID #10158080 is not in the node list
```

## 根本原因
`accesskit_consumer 0.32.0`（Slint 1.16.1 的間接依賴）的已知 bug：
- Slint `ComboBox` 點擊後開啟 popup，focus 被設為 popup 中的 node ID
- popup 關閉時，該 node 被移除
- 但 AccessKit tree 的 focus 欄位仍持有舊 ID → `validate_global` panic

## 修復方式
在 `ui/components/pages/create-instance-dialog.slint` 中：

1. 移除 `ComboBox` import（`std-widgets.slint`）
2. 新增 `ScrollView` import
3. 新增 component 級別屬性：`version-dropdown-open`、`loader-version-dropdown-open`
4. 將 Basic tab 的 `VerticalLayout` 改用 `ScrollView` 包裝（支援下拉展開後的捲動）
5. 兩個 `ComboBox` 換成「觸發 Rectangle + 條件展開的 ScrollView 清單」自訂元件
6. 切換 tab 時自動關閉下拉清單

## 影響範圍
- `create-instance-dialog.slint` 僅 UI 層變動，Rust 端 InstanceCreateLogic 全局屬性無需修改
- 功能等價：選版本、選 Mod Loader 版本行為不變，只是 UI 改為自訂 dropdown
